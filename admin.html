가계부 일괄 입력

JSON 배열을 붙여넣고 버튼 클릭 → Firebase에 저장
준비 중...
📖 사용법·필드 안내

필수 필드:

  • date: YYYY-MM-DD (예: "2026-08-07")
  • cat: 카테고리 ID (아래 참고)
  • amount: 숫자 (통화 단위, 예: 245000)
  • currency: "IDR" 또는 "KRW"

선택 필드:

  • memo: 메모 (선택)

카테고리 ID:

  • food 🍽️ 식비
  • transit 🚗 교통
  • activity 🎢 액티비티
  • shopping 🛍️ 쇼핑
  • spa 💆 마사지
  • tip 💵 팁
  • mart 🛒 편의·약
  • etc 📦 기타

예시:

[
  {"date":"2026-08-07","cat":"food","amount":245000,"currency":"IDR","memo":"Scallywags 저녁"},
  {"date":"2026-08-07","cat":"transit","amount":14000,"currency":"KRW","memo":"사누르→스랑안 픽업"},
  {"date":"2026-08-08","cat":"activity","amount":600000,"currency":"IDR","memo":"3길리 보트투어"}
]
